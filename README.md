# Income and Expense Analyzer

## About the Project

Income and Expense Analyzer is a beginner-level Python project that calculates total income, total expenses, and the final financial balance.

The program accepts five income amounts and five expense amounts from the user and generates a simple financial report.

## Features

- Accepts five income values.
- Accepts five expense values.
- Calculates total income and total expenses.
- Sorts income and expense amounts from lowest to highest.
- Displays the lowest and highest values.
- Calculates the final financial balance.
- Formats financial results to two decimal places.

## Concepts Practiced

- Variables and data types
- User input with `input()`
- Type conversion using `float()`
- Lists
- The built-in `sum()` function
- List sorting with `sort()`
- Formatted strings (f-strings)
- Basic arithmetic operations
- Console output with `print()`

## Requirements

- Python 3

No external libraries are required.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run the following command:

   ```bash
   python main.py
   ```

5. Enter five income amounts and five expense amounts when prompted.
